Нужно реализовать в текущем сервисе собственное получение реальной выдачи Яндекса без использования платных SERP-посредников.

Важно:
не использовать DataForSEO, SearchAPI и другие платные внешние SERP-провайдеры как обязательный источник.
Нужен собственный модуль съёма и парсинга Яндекс SERP.

Задача:
сервис должен сам получать реальную поисковую выдачу Яндекса по ключу и региону, затем сам выделять:
- органические результаты
- рекламные результаты

Что нужно сделать:

1. Реализовать собственный слой получения SERP.
Нужен модуль, который:
- принимает ключ
- принимает регион поиска
- делает запрос к Яндексу
- получает HTML поисковой выдачи

2. Реализовать парсер HTML выдачи.
Нужно выделять из страницы:
- тип блока: органика / реклама
- позицию
- заголовок
- описание
- URL
- домен

3. Рекламную выдачу нужно определять автоматически по HTML выдачи.
Не считать, что раз нет отдельного API, то рекламу определить нельзя.
Нужно именно распарсить рекламные блоки из SERP.

4. Слой аналитики не ломать.
Уже существующая логика должна остаться:
- текстовое совпадение
- тип страницы
- прямой конкурент
- гео-релевантность
- debug
- русский интерфейс

Нужно просто заменить источник данных:
не моки, не внешний платный посредник, а собственный съём HTML выдачи Яндекса.

5. Сделать архитектуру с разделением:
- fetcher: получает HTML
- parser: разбирает HTML
- normalizer: приводит к единому формату
- analysis: считает конкуренцию

6. Обязательно добавить debug-режим для проверки парсинга.
Нужно уметь видеть:
- сырой HTML или его фрагмент
- какие блоки распознаны как органика
- какие блоки распознаны как реклама
- какие селекторы сработали
- сколько результатов извлечено

7. Если Яндекс вернул капчу, ошибку, пустую выдачу или блокировку:
- это нужно явно определять
- не подставлять фиктивные результаты
- в интерфейсе честно показывать, что съём выдачи не удался

8. Подготовить решение так, чтобы потом можно было добавить:
- прокси
- ротацию IP
- headless browser при необходимости
Но сейчас сначала сделать рабочую базовую версию.

9. После реализации показать:
- какие файлы созданы/изменены
- как теперь сервис получает органику
- как теперь сервис определяет рекламу
- как понять, что анализ идёт по реальной выдаче
- как увидеть debug парсинга

Важно:
не переделывать проект с нуля,
а встроить собственный модуль реального съёма Яндекс SERP в текущую архитектуру.
