# Анализ конкурентности ключевых слов (Яндекс SERP)

## Назначение
Веб-сервис для оценки уровня реальной конкуренции по ключевым словам в Яндексе.
Пользователь вставляет список ключей, выбирает регион, запускает анализ и получает
таблицу с классификацией A–D и прозрачным debug-разбором каждого результата.

## Стек
- **Backend**: Python 3.11, FastAPI, pymorphy3, httpx, pydantic v2
- **Frontend**: React 18, TypeScript, Vite, CSS-модули

## Workflows
| Имя | Команда | Порт |
|-----|---------|------|
| Backend | `bash run.sh` | 8000 |
| Start application | `cd client && npm run dev` | 5000 |

Vite проксирует `/api` → `http://localhost:8000`.

## Архитектура backend (app/services/)

| Файл | Назначение |
|------|-----------|
| `serp_collector.py` | Запрос DataForSEO / fallback mock |
| `text_processor.py` | Лемматизация через pymorphy3, стоп-слова |
| `matcher.py` | Покрытие лемм, уровни STRONG/NEAR/PARTIAL/NONE |
| `intent_classifier.py` | **Новый**: классификация типа страницы (COMMERCIAL/MIXED/INFORMATIONAL/IRRELEVANT) по доменам и токенам |
| `scorer.py` | Формула оценки: базовый score × competitive_weight |
| `reporter.py` | Сборка отчёта: два слоя + debug, счётчики |
| `classifier.py` | Класс A–D по weighted_competition score; умные рекомендации |

## Трёхслойный анализ

### Слой 1 — текстовое совпадение
- Лемматизация ключа и заголовка/описания каждого результата
- Покрытие = доля лемм ключа, найденных в тексте
- Уровни: Полное (≥100%), Близкое (≥75%), Частичное (≥40%), Нет (<40%)

### Слой 2 — конкурентная релевантность
- Классификатор `intent_classifier.py` определяет тип страницы:
  - **COMMERCIAL** (вес 1.0) — прямой конкурент: маркетплейс, объявления, купить/продать/аренда
  - **MIXED** (вес 0.5) — частично конкурирует
  - **INFORMATIONAL** (вес 0.2) — информационная статья: советы, рейтинг, льготы, дизайн, дзен.ру
  - **IRRELEVANT** (вес 0.05) — государственный/справочный ресурс: госуслуги, mos.ru

### Итоговая формула
```
item_seo = (SEO_TITLE[title_level] + SEO_DESC[desc_level]) × competitive_weight
weighted_competition = Σ (competitive_weight × text_weight) по всем органическим
итог = seo_score × 0.8 + ads_score × 0.2
```

## Классы конкуренции
| Класс | weighted_competition | Описание |
|-------|---------------------|----------|
| A | ≤ 2.0 | Очень низкая |
| B | ≤ 5.0 | Умеренная |
| C | ≤ 9.0 | Заметная |
| D | > 9.0 | Высокая |

## Особенности UI
- Полностью на русском языке (нет Strong/Partial/None/COMMERCIAL в интерфейсе)
- Таблица с фильтрацией, сортировкой, экспортом CSV/JSON
- Кнопка «▼ Детали» раскрывает debug-панель с двумя слоями анализа
- В debug-панели: леммы ключа, таблица органики, таблица рекламы, разбивка оценок, легенда
